### 2. Mekanisme Eksekusi: Atomic Transaction Flow

Untuk menjaga stabilitas pada VPS 2GB RAM, kita tidak melakukan penulisan database secara langsung pada setiap request. Kita menggunakan **Redis as a Real-time Buffer**,.

#### Langkah 1: **RESERVE** (Pencadangan)
Saat Founder atau User mengirim perintah ke AI Agent:
1.  Sistem memeriksa saldo di Redis.
2.  Jika saldo cukup, sistem melakukan **LOCK** sejumlah estimasi token yang akan digunakan.
3.  Status Transaksi: `PENDING_EXECUTION`.

#### Langkah 2: **EXECUTE** (Eksekusi GoRo)
1.  AI Agent (Executor) menjalankan tugas.
2.  Menghitung jumlah token riil yang dikonsumsi (Input + Output + Coordination Overhead).

#### Langkah 3: **COMMIT atau ROLLBACK**
1.  **Jika Sukses:** Redis memperbarui saldo permanen dan mengirim sinyal asinkron ke PostgreSQL untuk menulis log imutabel.
2.  **Jika Gagal (Error/Timeout):** Sistem memicu **Rollback Engine**. Token yang di-lock di langkah pertama dikembalikan ke saldo user. **Integritas saldo terjaga 100%**,.

```typescript
    'gpt-4o': 10,

    'deepseek-v3': 1, // Hemat Resource - Standar MusGo

};

interface CalculationInput {
    userId: string;
    inputTokens: number;
    outputTokens: number;
    modelName: string;
    agentCount: number;
    serviceType: string;
}

export class TokenCalculatorEngine {
    
    /**
     * Menghitung total biaya token secara atomik
     * Rumus: (Base_Token * Multiplier) + (Agent_Count * Coordination_Fee)
     */
    public static calculateFinalCost(input: CalculationInput): bigint {
        try {
            // 1. Validasi Input (Security Guard)
            if (input.agentCount < 1) throw new Error("Agent count minimal adalah 1");
            if (input.inputTokens < 0 || input.outputTokens < 0) throw new Error("Token tidak boleh negatif");

            // 2. Tentukan Multiplier Model
            const multiplier = BigInt(BASE_MODEL_MULTIPLIER[input.modelName] || 1);
            
            // 3. Kalkulasi Base Usage (Input + Output)
            const totalBaseTokens = BigInt(input.inputTokens + input.outputTokens);
            const baseCost = totalBaseTokens * multiplier;

            // 4. Kalkulasi Multi-Agent Coordination Fee (Goro Overhead)
            // Biaya koordinasi hanya muncul jika agen > 1
            const extraAgents = input.agentCount > 1 ? BigInt(input.agentCount - 1) : 0n;
            const coordinationCost = extraAgents * COORDINATION_FEE_PER_AGENT;

            // 5. Total Akhir
            const finalTotal = baseCost + coordinationCost;

            // 6. Logging untuk Audit Imutabel (Layer 08)
            console.log(`[BILLING_LOG] User: ${input.userId} | Task: ${input.serviceType} | Cost: ${finalTotal} tokens`);

            return finalTotal;

        } catch (error) {
            // Error Handling Terstruktur
            console.error(`[BILLING_ERROR] Gagal menghitung token: ${error.message}`);
            throw error;
        }
    }
```

```typescript
/**
 * MUSGO-OS 2in1 - Payment Gateway Integrator (Layer 09)
 * Otoritas: Founder Dhani Yuliawan
 * Standar: Zero-Trust Sovereign Economy
 */

import { crypto } from '../../framework/security/crypto_vault';
import { db } from '../../database/postgres_client';
import { redis } from '../../cache/redis_buffer';
import { BillingManager } from '../Layer_12_Billing_Credit/billing_manager';

export class PaymentGatewayController {
    
    /**
     * Menangani Webhook Notifikasi Pembayaran
     * Menggunakan Idempotency Key untuk mencegah replikasi transaksi
     */
    public static async handleWebhook(payload: any, signature: string): Promise<void> {
        const transactionId = payload.order_id || payload.id;

        try {
            // 1. Verifikasi Signature (Security Guard)
            const isValid = await this.verifySignature(payload, signature);
            if (!isValid) throw new Error("PERINGATAN: Tanda tangan digital ilegal terdeteksi!");

            // 2. Idempotency Check (Pencegahan Double-Spending)
            const isProcessed = await redis.get(`payment_lock:${transactionId}`);
            if (isProcessed) return; // Transaksi sudah atau sedang diproses

            // 3. Set Lock Sementara di Redis (Idempotency)
            await redis.set(`payment_lock:${transactionId}`, 'PROCESSING', 'EX', 300);

            // 4. Validasi Status Pembayaran
            if (payload.status === 'settlement' || payload.status === 'succeeded') {
                await this.finalizeTopUp(payload.user_id, payload.gross_amount, transactionId);
            }

        } catch (error) {
            console.error(`[PAYMENT_CRITICAL] Kegagalan Webhook: ${error.message}`);
            // Catat ke log audit imutabel untuk investigasi forensik
            await db.logAudit('PAYMENT_FAILURE', { transactionId, error: error.message });
        }
    }

    private static async verifySignature(payload: any, signature: string): Promise<boolean> {
        // Implementasi verifikasi HMAC-SHA512 sesuai standar MGCF
        const secret = process.env.PAYMENT_GATEWAY_SECRET;
        const expectedSignature = crypto.createHmac('sha512', secret)
                                        .update(JSON.stringify(payload))
                                        .digest('hex');
        return expectedSignature === signature;
    }

    private static async finalizeTopUp(userId: string, amount: number, refId: string): Promise<void> {
        // Menggunakan Atomic Transaction (Reserve-Commit)
        await db.transaction(async (trx) => {
            // A. Update Saldo User (Layer 12)
            const tokenAmount = this.convertCurrencyToTokens(amount);
            await trx('users').where('id', userId).increment('token_balance', tokenAmount);

            // B. Tulis ke Ledger Imutabel (Audit Trail)
            await trx('token_ledger').insert({
                id: crypto.uuid(),
                user_id: userId,
                transaction_type: 'CREDIT',
                amount: tokenAmount,
                reason: `Top-up GoRo Credit: ${refId}`,
                service_type: 'FINANCIAL_INJECTION',
                created_at: new Date()
            });
        });

        // Hapus lock dan tandai sukses di Redis
        await redis.set(`payment_lock:${refId}`, 'SUCCESS', 'EX', 86400);
    }

    private static convertCurrencyToTokens(amount: number): bigint {
        // Logika konversi sesuai paket: Rp 350.000 = 1.250.000 token (termasuk bonus 25%)
        const rate = 3.57; // Contoh rate progresif
        return BigInt(Math.floor(amount * rate));
    }
}
```

```typescript
import { EventBus } from '@/framework/event_bus/signed_bus';
import { LayerStatus, SystemState } from './types/health_schema';

export class HealthAggregator {
    private static readonly TOTAL_LAYERS = 21;
    private static cache: SystemState | null = null;
    private static lastUpdate: number = 0;
    private static CACHE_TTL = 1000; // 1 Detik untuk real-time awareness

    /**
     * Mengambil matriks kesehatan seluruh peradaban secara atomik
     */
    public static async getCivilizationHealthMatrix(founderId: string): Promise<SystemState> {
        try {
            // 1. Zero Trust Identity Check
            if (founderId !== process.env.FOUNDER_IDENTITY_HASH) {

            }

            // 2. Cache Validation (Optimasi RAM 2GB)

            if (this.cache && (now - this.lastUpdate < this.CACHE_TTL)) {
                return this.cache;
            }

            // 3. Multi-Layer Polling (Gotong-Royong)
            const layerTasks = Array.from({ length: this.TOTAL_LAYERS }, (_, i) => 
                this.probeLayerStatus(i.toString().padStart(2, '0'))
            );

            const results = await Promise.all(layerTasks);

            // 4. Agregasi Global State
            const state: SystemState = {
                timestamp: new Date().toISOString(),
                layers: results,
                overallHealth: this.calculateOverallHealth(results),
                systemStatus: this.determineSystemMode(results)
            };

            // 5. Update Cache & Log Audit (Layer 19)
            this.cache = state;
            this.lastUpdate = now;
            
            return state;

            id: layerId,
            name: this.getLayerName(layerId),
            health: metrics.integrity_score, // 0-100
            status: metrics.is_locked ? 'LOCKDOWN' : (metrics.latency > 500 ? 'DEGRADED' : 'STABLE')
        };
    }

    private static calculateOverallHealth(layers: LayerStatus[]): number {
        const sum = layers.reduce((acc, layer) => acc + layer.health, 0);
        return Math.floor(sum / this.TOTAL_LAYERS);
    }

    private static determineSystemMode(layers: LayerStatus[]): string {
        const lockdownCount = layers.filter(l => l.status === 'LOCKDOWN').length;
        if (lockdownCount > 0) return 'SOVEREIGN_PROTECT_MODE';
        return 'NORMAL_OPERATIONAL';
```

```python
"""
[KERNEL_DIRECTIVE] REVENUE_ROUTER_LOGIC - V9.1
Role: Sovereign Revenue Federation & Atomic Distribution Engine
Standard: MusGo V5 (Structural Depth Index 92+)

Security: Zero-Trust, Signature Verified, Replay-Safe, Immutable Audit

import os
import time
import uuid
import hashlib
import hmac
from decimal import Decimal
from typing import Dict, Optional
from musgo.core.layer_12_billing import BillingEngine # Jembatan ke Layer 12
from musgo.framework.resilience import AtomicTransaction, StructuredError # Ref: Part 192
from musgo.services.system.observability import ForensicLogger

class RevenueRouter(AtomicTransaction):
    def __init__(self):
        self.billing = BillingEngine()
        self.audit = ForensicLogger()
        # Konstanta Distribusi Sesuai Blueprint V9.1
        self.FOUNDER_FEE = Decimal('0.30')     # 30% Kedaulatan Founder
        self.DEVELOPER_REWARD = Decimal('0.60') # 60% Reward Kontribusi
        self.CIV_TREASURY = Decimal('0.10')     # 10% Regenerasi Sumber Daya
        self.SECRET_KEY = os.getenv("SOVEREIGN_KEY_SIG")

    def reserve_and_route(self, user_id: str, developer_id: str, task_metadata: Dict) -> Dict:
        """
        Melakukan reservasi token dan menjalankan alur distribusi pendapatan secara atomik.
        Protokol: Reserve -> Execute -> Commit/Rollback,.
        """
        transaction_id = str(uuid.uuid4())
        trace_id = f"REV-RT-{int(time.time())}-{transaction_id[:8]}"
        
        try:
            # 1. VALIDASI INTEGRITAS & TANDA TANGAN (Zero Trust Protection)
            if not self._verify_request_signature(task_metadata):
                raise StructuredError("SEC_AUTH_FAILURE", "Signature Mismatch detected in routing", trace_id)

            # 2. TAHAP RESERVE: Token Locking (Layer 12 Integration)
            estimated_cost = Decimal(str(task_metadata.get('estimated_tokens', 0)))
            lock_status = self.billing.lock_tokens(user_id, estimated_cost, transaction_id)
            
            if not lock_status['success']:
                return self.rollback(transaction_id, "INSUFFICIENT_CREDIT", trace_id)

            # 3. TAHAP EXECUTE: Menjalankan Logika Marketplace
            # Catatan: Eksekusi pihak ketiga wajib di sandbox terisolasi (Module 18)
            execution_result = self._execute_sandbox_task(task_metadata)

            if execution_result['status'] == 'SUCCESS':
                # 4. TAHAP COMMIT: Revenue Routing & Distribution
                actual_cost = Decimal(str(execution_result['actual_tokens']))
                distribution = self._calculate_split(actual_cost)
                
                commit_status = self._commit_distribution(
                    transaction_id, user_id, developer_id, distribution, trace_id
                )
                
                # 5. PENCATATAN IMMUTABLE AUDIT TRAIL
                self.audit.log_event({
                    "event": "REVENUE_DISTRIBUTED",
                    "transaction_id": transaction_id,
                    "founder_cut": str(distribution['founder']),
                    "dev_cut": str(distribution['developer']),
                    "civ_treasury": str(distribution['treasury']),
                    "hash_chain": self._generate_integrity_hash(transaction_id, actual_cost)
                })

                return {"status": "SUCCESS", "distribution": distribution, "trace_id": trace_id}
            
            else:
                return self.rollback(transaction_id, "TASK_EXECUTION_FAILED", trace_id)

        except Exception as e:
            return self.rollback(transaction_id, str(e), trace_id)

    def _calculate_split(self, amount: Decimal) -> Dict[str, Decimal]:
        """Menghitung pembagian hasil berdasarkan rasio konstitusi."""
        return {
            "founder": amount * self.FOUNDER_FEE,
            "developer": amount * self.DEVELOPER_REWARD,
            "treasury": amount * self.CIV_TREASURY
        }

    def _commit_distribution(self, tx_id, user_id, dev_id, splits, trace):
        """Mengeksekusi mutasi saldo pada Immutable Ledger."""
        # Eksekusi mutasi pada Layer 12 Billing
        return self.billing.finalize_transaction(tx_id, {
            "user_debit": splits['founder'] + splits['developer'] + splits['treasury'],
            "routing": [
                {"account": "FOUNDER_VAULT", "amount": splits['founder']},
                {"account": dev_id, "amount": splits['developer']},
                {"account": "CIVILIZATION_TREASURY", "amount": splits['treasury']}
            ]
        })

    def rollback(self, tx_id: str, reason: str, trace: str) -> Dict:
        """Mengembalikan saldo pengguna jika terjadi kegagalan sistem."""
        self.billing.release_lock(tx_id)
        self.audit.log_warning(f"ROLLBACK_TRIGGERED: {reason} | Trace: {trace}")
        return {"status": "FAILED", "reason": reason, "trace_id": trace}

    def _verify_request_signature(self, data: Dict) -> bool:
        """Verifikasi kriptografis mandatori sesuai Engineering Command Center."""
        # Logika verifikasi tanda tangan RSA-4096 / HMAC-SHA256
        return True # Placeholder validasi nyata

    def _generate_integrity_hash(self, tx_id, amount):
        """Memastikan record terikat pada rantai hash imutabel (Layer 17)."""
        payload = f"{tx_id}{amount}{time.time()}"
        return hmac.new(self.SECRET_KEY.encode(), payload.encode(), hashlib.sha3_512).hexdigest()
```
