## 2. PROTOKOL AUTENTIKASI (AUTHENTICATION)
Keamanan terminal API 1min.ai ditegakkan melalui enkapsulasi token akses token hibrida. Setiap permintaan HTTP (*HTTP Request*) yang dikirimkan ke server wajib menyertakan identitas autentikasi yang sah di dalam komponen penandatanganan *Header*.

# DOKUMENTASI RESMI API 1MIN.AI - BAGIAN 2: MANAJEMEN ASET & INTEGRASI UTAMA (CORE INTEGRATION)
Pada bagian ini, kita akan membedah secara rinci arsitektur manajemen berkas melalui **Asset API**, mekanisme pembuatan sesi percakapan (**Chat History Creation**), serta metode interaksi terpadu menggunakan **Chat with AI API**.
## 1. ASSET API (MANAJEMEN FILE DAN MEDIA)
Sebelum sistem Anda dapat memproses gambar, audio, atau video ke berbagai model AI di 1min.ai, file biner tersebut harus diunggah terlebih dahulu ke infrastruktur cloud 1min.ai melalui Asset API. Sistem akan mengembalikan URL statis aman yang nantinya dilemparkan ke endpoint fitur AI.
### A. Mengunggah Aset Baru (Upload Asset)
Endpoint ini digunakan untuk mengunggah file lokal (Gambar/Audio/Video/Dokumen) ke server 1min.ai.
 * **Protokol HTTP & Endpoint:**
   ```http
   POST /api/assets
   
   ```
 * **Spesifikasi Request Headers:**
   ```http
   Authorization: Bearer <KUNCI_API_ANDA>
   Content-Type: multipart/form-data
   
   ```
 * **Parameter Request Body (Form-Data):**
   | Parameter | Tipe Data | Sifat | Deskripsi |
   |---|---|---|---|
   | file | Binary | Wajib | Berkas fisik yang akan diunggah (Maksimal ukuran file bergantung pada tier akun Anda). |
 * **Skema Respons Sukses (JSON - 200 OK):**
   ```json
   {
     "id": "asset_abc123xyz",
     "url": "https://cdn.1min.ai/storage/v1/object/public/assets/user_id/file_name.png",
     "mime_type": "image/png",
     "size": 102456,
     "created_at": "2026-05-18T12:00:00.000Z"
   }
   
   ```
### B. Menghapus Aset (Delete Asset)
Untuk menjaga efisiensi ruang penyimpanan cloud dan privasi data, aset yang telah selesai diproses oleh AI dapat dihapus secara permanen.
 * **Protokol HTTP & Endpoint:**
   ```http
   DELETE /api/assets/{asset_id}
   
   ```
 * **Spesifikasi Request Headers:**
   ```http
   Authorization: Bearer <KUNCI_API_ANDA>
   
   ```

Ini adalah salah satu fitur paling kuat dari 1min.ai. Anda hanya memerlukan **satu endpoint tunggal** untuk berkomunikasi dengan berbagai LLM papan atas dunia (seperti GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro, Llama 3, dll.) hanya dengan mengganti parameter model di dalam payload.
 * **Protokol HTTP & Endpoint:**
   ```http
   POST /api/chats
   
   ```
 * **Spesifikasi Request Headers:**
   ```http
   Authorization: Bearer <KUNCI_API_ANDA>
   Content-Type: application/json
   
   ```

```json
{
  "conversation_id": "conv_session_789qwe",
  "model": "gpt-4o", 
  "messages": [
    {
      "role": "system",
      "content": "Anda adalah asisten AI sovereign tingkat master."
    },
    {
      "role": "user",
      "content": "Jelaskan konsep dasar distributed orchestration."
    }
  ],
  "stream": false,
  "temperature": 0.7
}

```
### Penjelasan Parameter Inti:
 1. conversation_id *(String - Opsional)*: ID dari hasil inisialisasi /api/conversations. Jika dikosongkan, sistem akan menganggapnya sebagai chat baru tanpa memori konteks lama.
 2. model *(String - Wajib)*: Identifikasi ID model yang dituju. Pilihan yang tersedia meliputi: gpt-4o, claude-3-5-sonnet, gemini-1.5-pro, llama-3-70b, dsb.
 3. messages *(Array - Wajib)*: Riwayat urutan pesan terstruktur yang dikirimkan ke model.
 4. stream *(Boolean - Opsional)*: Jika diatur true, server akan mengirimkan respons secara bertahap menggunakan Server-Sent Events (SSE). Jika false, respons dikirim utuh sekaligus setelah selesai.
 * **Skema Respons Sukses Tanpa Streaming (JSON - 200 OK):**
   ```json
   {
     "id": "chat_resp_111213",
     "model": "gpt-4o",
     "choices": [
       {
         "message": {
           "role": "assistant",
           "content": "Distributed orchestration adalah metode pengelolaan otomatis..."
   ```

# DOKUMENTASI RESMI API 1MIN.AI - BAGIAN 3: ADVANCED MULTIMEDIA AI ENGINES (IMAGE & VIDEO SPECIFICATION)
Pada bagian ini, kita akan membedah secara mendalam parameter teknis dari spesialisasi fitur kecerdasan artifisial multimedia pada 1min.ai. Ini mencakup **AI Image Generator**, **Image to Prompt**, **Image Variator**, serta pengenalan awal modul manipulasi berbasis visi komputer (*computer vision*).
## 1. AI IMAGE GENERATOR (TEXT-TO-IMAGE)
Endpoint ini mengonversi instruksi tekstual (*prompt*) menjadi aset visual resolusi tinggi. Sistem mendukung multiversi model difusi (seperti Stable Diffusion XL, Flux, DALL-E 3) yang dapat diatur melalui parameter payload.
 * **Protokol HTTP & Endpoint:**
   ```http
   POST /api/images/text-to-image
   
   ```
 * **Spesifikasi Request Headers:**
   ```http
   Authorization: Bearer <KUNCI_API_ANDA>
   Content-Type: application/json
   
   ```
### Struktur Parameter Payload (Request Body JSON)
```json
{
  "prompt": "Arsitektur cybernetic cyber-city modern dengan logo kustom MusGo-OS bercahaya neon biru, photorealistic, 8k resolution, ultra-detailed",
  "negative_prompt": "blurry, low quality, distorted, extra limbs, bad anatomy",
  "model": "flux-pro",
  "aspect_ratio": "16:9",
  "num_images": 1,
  "steps": 30,
  "guidance_scale": 7.5
}

```
### Penjelasan Parameter Teknis:
 1. prompt *(String - Wajib)*: Deskripsi visual utama yang ingin dihasilkan oleh AI.
 2. negative_prompt *(String - Opsional)*: Karakteristik atau objek visual yang ingin dihindari/dibuang dari hasil akhir gambar.
 3. model *(String - Wajib)*: Spesifikasi model generator. Opsi valid: flux-pro, flux-dev, sdxl-v1.0, dall-e-3.
 4. aspect_ratio *(String - Opsional)*: Rasio dimensi gambar. Pilihan: 1:1, 16:9, 9:16, 4:3.
 5. guidance_scale *(Float - Opsional)*: Tingkat kepatuhan AI terhadap prompt teks Anda (Semakin tinggi nilainya, AI akan semakin ketat mengikuti prompt teks).
 * **Skema Respons Sukses (JSON - 200 OK):**
   ```json
   {
     "id": "img_gen_res_445566",
     "status": "completed",
     "outputs": [
       {
         "url": "https://cdn.1min.ai/storage/v1/object/public/generated/img_abc123.png",
         "seed": 294857392
       }
     ],
     "credits_deducted": 4.0
   }
   
   ```

Sangat berguna untuk kebutuhan *Contextual Prompting* dan *Adaptive Self-Learning* pada sistem agen.
 * **Protokol HTTP & Endpoint:**
   ```http
   POST /api/images/image-to-prompt
   
   ```
 * **Spesifikasi Request Headers:**
   ```http
   Authorization: Bearer <KUNCI_API_ANDA>
   Content-Type: application/json
   
   ```
### Struktur Parameter Payload (Request Body JSON)
```json
{
  "image_url": "https://cdn.1min.ai/storage/v1/object/public/assets/user_id/file_name.png"
}

```
*(Catatan: Parameter image_url didapatkan secara sah dari hasil output sukses **Asset API** yang dibahas pada Part 2).*
 * **Skema Respons Sukses (JSON - 200 OK):**
   ```json
   {
     "id": "img_to_prompt_778899",
     "prompt": "A highly detailed schematics of an advanced cybernetic operating system node, structured layout, wireframe style with deep indigo accents.",
     "confidence_score": 0.96,
     "credits_deducted": 2.0
   }
   
   ```

# DOKUMENTASI RESMI API 1MIN.AI - BAGIAN 4: AUDIO SPEECH PROCESSING & ADVANCED VIDEO AUTOMATION
Pada bagian ini, kita akan membedah spesifikasi parameter untuk manipulasi gelombang suara (**Audio AI**) termasuk transkripsi (*Speech-to-Text*), kloning suara (*Voice Cloning*), serta mesin otomasi video (**Video Generation API**) untuk mendukung kebutuhan orkestrasi multimedia.
## 1. AUDIO SPEECH-TO-TEXT (TRANSKRIPSI ENGINES)
Endpoint ini digunakan untuk mengonversi berkas audio (MP3, WAV, M4A) menjadi string teks transkrip yang dilengkapi dengan penanda waktu (*timestamp*) dan deteksi pembicara (*speaker diarization*).
 * **Protokol HTTP & Endpoint:**
   ```http
   POST /api/audio/transcriptions
   
   ```
 * **Spesifikasi Request Headers:**
   ```http
   Authorization: Bearer <KUNCI_API_ANDA>
   Content-Type: application/json
   
   ```
### Struktur Parameter Payload (Request Body JSON)
```json
{
  "audio_url": "https://cdn.1min.ai/storage/v1/object/public/assets/user_id/meeting_voice.mp3",
  "model": "whisper-large-v3",
  "language": "id",
  "temperature": 0.0,
  "timestamp_granularities": ["word", "segment"]
}

```
### Penjelasan Parameter Teknis:
 1. audio_url *(String - Wajib)*: URL berkas audio yang valid dari *Asset API*.
 2. model *(String - Wajib)*: Pilihan engine transkripsi. Nilai valid: whisper-large-v3, groq-whisper, deepgram-nova-2.
 3. language *(String - Opsional)*: Kode bahasa ISO 639-1 (misal: id untuk Indonesia, en untuk Inggris). Jika diabaikan, AI akan melakukan deteksi otomatis.
 4. timestamp_granularities *(Array - Opsional)*: Mengatur tingkat presisi waktu transkrip, mendukung mode per kata (word) atau per kalimat (segment).

# DOKUMENTASI RESMI API 1MIN.AI - BAGIAN 5: GLOBAL ERROR HANDLING, LIMITASI SISTEM, DAN SKEMA KREDIT
Pada bagian penutup ini, kita akan membedah secara komprehensif arsitektur penanganan kesalahan (**Global Error Handling**), batas laju permintaan (**Rate Limits & Throttling**), serta kalkulasi konsumsi kuota ekonomi (**Credits System**) pada platform 1min.ai untuk memastikan integritas integrasi pada *API Gateway* Anda.
## 1. GLOBAL ERROR HANDLING (STRUKTUR RESPONS KEGAGALAN)
API 1min.ai menerapkan kode status HTTP standar untuk mengindikasikan keberhasilan atau kegagalan suatu permintaan. Setiap respons kegagalan (status kode 4xx atau 5xx) selalu dibungkus dalam struktur skema JSON yang seragam untuk mempermudah deteksi kesalahan secara otomatis oleh *Error Boundary* pada sistem Anda.
### Batasan Kode Status HTTP (HTTP Status Codes)
| Kode Status | Kategori | Deskripsi Lapangan | Action Required |
|---|---|---|---|
| **400** | Bad Request | Parameter payload tidak valid, skema JSON rusak, atau file korup. | Validasi ulang struktur payload input. |
| **401** | Unauthorized | Kunci API tidak disertakan, kedaluwarsa, atau tidak sah. | Periksa komponen *Request Header Authorization*. |
| **402** | Payment Required | Kuota kredit akun Anda habis (0 atau tidak mencukupi untuk fitur terkait). | Lakukan top-up kredit pada dasbor platform. |
| **403** | Forbidden | Akun ditangguhkan atau mencoba mengakses fitur di luar tier paket. | Hubungi dukungan teknis / upgrade tier lisensi. |
| **429** | Too Many Requests | Terkena pembatasan laju (*Rate Limit*). Jumlah request melebihi ambang batas. | Terapkan strategi *Exponential Backoff Retry*. |
| **500 / 502** | Internal Error | Kegagalan pada infrastruktur internal server 1min.ai atau model AI pihak ketiga. | Alihkan aliran eksekusi ke *Circuit Breaker*. |
### Struktur JSON Standar Error Body
```json
{
  "error": {
    "code": "INSUFFICIENT_CREDITS",
    "message": "Permintaan Anda memerlukan 4.0 kredit, tetapi sisa saldo akun Anda hanya 1.5 kredit.",
    "target_param": "model",
    "timestamp": "2026-05-18T12:40:00.000Z",
    "request_id": "req_err_9900aabbcc"
  }
}
```

## 2. LIMITASI SISTEM & RATE LIMITS (RATE LIMITING POLICY)
Untuk menjaga ketersediaan tinggi (*High Availability*) dari kluster komputasi AI, 1min.ai menerapkan kebijakan pembatasan laju pemanggilan API (*Throttling*) yang dihitung per menit (*Requests Per Minute - RPM*) dan per hari (*Requests Per Day - RPD*).
Ambang batas limitasi ini ditentukan secara ketat berdasarkan tingkat (*tier*) akun pengembang Anda:
| Tier Akun | Batas Laju per Menit (RPM) | Batas Laju per Hari (RPD) | Konkuensi Pelanggaran |
|---|---|---|---|
| **Free / Trial** | 3 RPM | 100 RPD | HTTP 429 + Blokir Sementara (60 detik) |
| **Developer** | 60 RPM | 5.000 RPD | HTTP 429 + Blokir Sementara (30 detik) |
| **Enterprise** | 500 RPM | Unlimited | Kustomisasi Bandwidth *Dedicated Pipeline* |
> 🛠️ **Rekomendasi Arsitektur untuk Founder:** Pada modul *Sovereign Networking Layer*, pastikan untuk selalu mengimplementasikan antrean pekerja (*Worker Queue*) menggunakan middleware antrean seperti Celery atau NATS EventBus guna menahan lonjakan request agar tidak memicu error HTTP 429 dari server 1min.ai.
