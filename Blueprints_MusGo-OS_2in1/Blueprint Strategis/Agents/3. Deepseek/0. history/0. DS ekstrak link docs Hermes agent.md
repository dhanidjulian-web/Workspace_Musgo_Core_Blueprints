# Panduan Memulai Cepat Hermes Agent

Panduan ini akan membawa Anda dari nol ke pengaturan Hermes yang berfungsi dan siap digunakan. Kita akan menginstal, memilih penyedia, memverifikasi obrolan yang berfungsi, dan mengetahui persis apa yang harus dilakukan jika ada yang salah.

## Untuk Siapa Panduan Ini?
- Anda baru dan menginginkan jalur terpendek menuju pengaturan yang berfungsi.
- Anda mengganti penyedia dan tidak ingin kehilangan waktu karena kesalahan konfigurasi.
- Anda menyiapkan Hermes untuk tim, bot, atau alur kerja yang selalu aktif.
- Anda lelah dengan "telah terinstal, tetapi tetap tidak melakukan apa pun".

## Jalur Tercepat

Pilih baris yang sesuai dengan tujuan Anda:

| Tujuan | Lakukan ini dulu | Kemudian lakukan ini |
|---|---|---|
| Saya hanya ingin Hermes berfungsi di mesin saya | `hermes setup` | Jalankan obrolan nyata dan pastikan ia merespons |
| Saya sudah tahu penyedia saya | `hermes model` | Simpan konfigurasi, lalu mulai mengobrol |
| Saya ingin bot atau pengaturan yang selalu aktif | `hermes gateway setup` setelah CLI berfungsi | Hubungkan Telegram, Discord, Slack, atau platform lain |
| Saya ingin model lokal atau yang di-host sendiri | `hermes model` → custom endpoint | Verifikasi endpoint, nama model, dan panjang konteks |
| Saya ingin fallback multi-penyedia | `hermes model` terlebih dahulu | Tambahkan routing dan fallback hanya setelah obrolan dasar berfungsi |

**Aturan praktis:** jika Hermes tidak dapat menyelesaikan obrolan normal, jangan tambahkan fitur lain dulu. Dapatkan satu percakapan yang bersih terlebih dahulu, baru kemudian lapisi dengan gateway, cron, skill, suara, atau routing.

---

## 1. Instal Hermes Agent

### Opsi A — pip (paling sederhana)
```bash
pip install hermes-agent
hermes postinstall   # opsional: menginstal Node.js, browser, ripgrep, ffmpeg + menjalankan setup
```

Rilis PyPI mengikuti versi yang ditandai (rilis mayor/minor), bukan setiap commit di `main`. Untuk versi terbaru, gunakan Opsi B.

### Opsi B — git installer (mengikuti branch main)
```bash
# Linux / macOS / WSL2 / Android (Termux)
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
```

**Android / Termux:** Jika Anda menginstal di ponsel, lihat panduan Termux khusus untuk jalur manual yang telah diuji, ekstra yang didukung, dan keterbatasan khusus Android saat ini.

**Pengguna Windows:** Instal [WSL2](https://learn.microsoft.com/en-us/windows/wsl/install) terlebih dahulu, lalu jalankan perintah di atas di dalam terminal WSL2 Anda. Setelah selesai, muat ulang shell Anda:
```bash
source ~/.bashrc   # atau source ~/.zshrc
```

Untuk opsi instalasi detail, prasyarat, dan pemecahan masalah, lihat [Panduan Instalasi](https://hermes-agent.nousresearch.com/docs/getting-started/installation).

Pada bagian selanjutnya, kita akan membahas pemilihan penyedia AI dan verifikasi bahwa setup Anda berfungsi. Apakah Anda siap untuk melanjutkan ke bagian berikutnya?

## 2. Memilih Penyedia Model

Setelah instalasi selesai, langkah berikutnya adalah memilih penyedia AI (model) yang akan digunakan Hermes.

### Perintah Dasar
```bash
hermes model
```

Perintah ini akan memandu Anda melalui:
- Pemilihan penyedia (OpenAI, Anthropic, Groq, Together AI, Ollama, LM Studio, atau custom endpoint)
- Memasukkan kunci API (jika diperlukan)
- Menguji koneksi ke model

### Penyedia yang Didukung

| Penyedia | Model Contoh | API Key Diperlukan? |
|---|---|---|
| OpenAI | gpt-4o, gpt-4-turbo, gpt-3.5-turbo | Ya |
| Anthropic | claude-3-opus, claude-3-sonnet | Ya |
| Groq | llama3-70b, mixtral-8x7b | Ya (gratis tier tersedia) |
| Together AI | llama3, mixtral, hermes-2-pro | Ya |
| Ollama (lokal) | llama3, hermes-pro, phi3 | Tidak (localhost) |
| LM Studio (lokal) | model apa pun yang dimuat | Tidak |
| Custom Endpoint | server OpenAI-compatible | Tergantung |

### Langkah Praktis: Menggunakan Groq (Cepat & Gratis)

1. Daftar di [Groq Console](https://console.groq.com)
2. Buat API key
3. Jalankan:
```bash
hermes model
```
4. Pilih `groq` dari daftar
5. Tempel API key saat diminta
6. Pilih model (misal: `llama3-70b-8192`)
7. Tunggu verifikasi berhasil

### Langkah Praktis: Menggunakan Ollama (Lokal, Tanpa Internet)

1. Instal Ollama dari [ollama.com](https://ollama.com)
2. Pull model:
```bash
ollama pull hermes-pro
```
3. Jalankan Hermes:
```bash
hermes model
```
4. Pilih `ollama`
5. Masukkan nama model (misal: `hermes-pro`)
6. Verifikasi koneksi

### Setelah Konfigurasi Berhasil

File konfigurasi akan tersimpan di:
- `~/.hermes/config.json` (Linux/macOS)
- `%USERPROFILE%\.hermes\config.json` (Windows)

Untuk melihat konfigurasi saat ini:
```bash
hermes config show
```

## 3. Verifikasi Obrolan

Jangan lewati langkah ini! Sebuah obrolan yang berfungsi adalah fondasi segalanya.

### Obrolan Sederhana
```bash
hermes chat
```

Atau langsung dengan pesan:
```bash
hermes chat --message "Apa ibukota Jepang?"
```

### Yang Diharapkan Terjadi
- Hermes akan memproses pesan Anda
- Model akan merespons (dalam beberapa detik hingga menit tergantung penyedia)
- Anda bisa melanjutkan percakapan interaktif

### Jika Gagal (Troubleshooting Cepat)

| Gejala | Kemungkinan Penyebab | Solusi |
|---|---|---|
| `API key invalid` | Key salah atau kedaluwarsa | `hermes model` → pilih ulang penyedia, masukkan key baru |
| `Connection timeout` | Jaringan bermasalah / endpoint salah | Cek koneksi internet. Untuk custom endpoint, pastikan URL benar. |
| `Model not found` | Nama model tidak dikenal | Jalankan `hermes model` lagi, pilih dari daftar yang tersedia. |
| `Rate limit exceeded` | Terlalu banyak permintaan | Tunggu beberapa menit, atau upgrade tier penyedia. |
| `Empty response` | Model tidak merespons | Coba model lain melalui `hermes model`. |

### Obrolan dengan Sistem Prompt Kustom
```bash
hermes chat --system "Anda adalah asisten yang hanya menjawab dalam bentuk puisi."
```

### Keluar dari Obrolan Interaktif
Tekan `Ctrl+C` atau ketik `exit` lalu Enter.

## 4. Langkah Selanjutnya

Setelah obrolan dasar berfungsi, Anda bisa menambahkan kemampuan lanjutan sesuai kebutuhan:

### Gateway (Bot untuk Telegram, Discord, Slack)
```bash
hermes gateway setup
```
Panduan interaktif akan membantu menghubungkan platform pilihan Anda.

### Menambahkan Skill (Tools / Function Calling)
Skill memungkinkan Hermes menjalankan perintah sistem, mencari web, atau mengakses API.
```bash
hermes skill add --name calculator --script ./calc.py
```
Dokumentasi lengkap: [Skill Guide](https://hermes-agent.nousresearch.com/docs/skills)

### Multi-Provider dengan Fallback
Edit `~/.hermes/config.json` secara manual atau gunakan:
```bash
hermes model add --provider openai --fallback groq
```
Ini akan otomatis beralih ke Groq jika OpenAI gagal.

### Mode Headless (Untuk Skrip & Otomatisasi)
```bash
hermes run --prompt "Tulis ringkasan dari berita terbaru" --no-stream
```

### Seluruh Dokumentasi
Kunjungi: [Hermes Agent Docs](https://hermes-agent.nousresearch.com/docs)
