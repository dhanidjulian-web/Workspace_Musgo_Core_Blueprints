## 2. Sovereign Authority Scope

Governor Layer holds exclusive authority to:

- Enforce constitutional compliance
- Activate sovereign lockdown
- Validate legal integrity of operations
- Approve or reject execution paths
- Validate constitution signature
- Validate core fingerprint integrity
- Publish governance decisions to signed event ledger

## 3. Lockdown Protocol

Governor may activate SOVEREIGN_LOCKDOWN under the following conditions:

- Constitution signature mismatch
- Core fingerprint integrity violation
- Detected IP tampering
- Severe system breach
- Legal violation escalation
- Founder override command

When lockdown is active:

- All execution requests must be rejected
- All lifecycle transitions must halt
- System remains in read-only governance mode

---

## 4. Founder Override Clause

A Founder Override Token may temporarily bypass non-constitutional restrictions.

Conditions:

- Token must match registered secure environment token
- All override actions must be logged
- All override actions must be signed and hashchain-anchored
- Override does not invalidate constitutional rules

Founder override cannot disable IP integrity validation.
