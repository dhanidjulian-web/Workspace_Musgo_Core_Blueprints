Berikut adalah daftar lengkap link dokumentasi resmi untuk berbagai platform AI terkemuka, mencakup penyedia model frontier, alat lokalisasi (self-hosted), infrastruktur cloud, pustaka machine learning (ML), hingga penyedia layanan deployment AI:
## 1. Frontier AI & Commercial LLM Providers
Platform yang menyediakan API untuk model bahasa besar (LLM), multimodal, pembuatan gambar, hingga agen kecerdasan buatan. [1, 2] 

* OpenAI: Panduan API GPT, asisten otomatis, serta dokumentasi teknis komprehensif tersedia di [OpenAI API Platform Documentation](https://developers.openai.com/api/docs).
* xAI (Grok): Pelajari integrasi model Grok, fitur reasoning, pemrosesan teks, serta pembuatan media di [xAI Docs: Overview](https://docs.x.ai/overview).
* Google Gemini: API key, fitur long context, pemahaman dokumen, dan SDK resmi tersedia di Gemini API Documentation.
* DeepSeek: Integrasi API yang kompatibel dengan format OpenAI untuk model penalaran (reasoning) hemat biaya melalui DeepSeek API Platform.
* Anthropic (Claude): Panduan pembuatan prompt sistem, API Claude, dan integrasi multi-agent tersedia pada Anthropic Developer Center. [3, 4, 5, 6, 7] 

## 2. Local AI & Open-Weights Models
Ekosistem untuk menjalankan model AI secara mandiri (self-hosted) di komputer atau server lokal.

* Ollama: Cara menjalankan model open-source (seperti Llama, Gemma, Mistral) secara lokal dan kelola API chat lokal di [Ollama's Documentation](https://docs.ollama.com/macos).
* Meta Llama: Panduan arsitektur model, bobot open-weights, metode fine-tuning, dan instruksi deployment di Meta Llama Documentation.
* Alibaba Cloud Qwen: Dokumentasi teknis, instruksi deployment, dan variasi model bahasa serta multimodal Qwen tersedia di Qwen Documentation Hub.
* Hugging Face: Pusat repositori model open-source. Akses dokumentasi pustaka Transformers, Datasets, dan ekosistem AI di Hugging Face Documentation. [2, 8, 9, 10] 

## 3. AI Infrastructure & Hardware Optimization
Platform penyedia akselerasi perangkat keras, pustaka tingkat rendah (low-level), dan optimasi model.

* NVIDIA AI: Panduan optimalisasi AI menggunakan TensorRT, komputasi CUDA, NIM (NVIDIA Inference Microservices), dan SDK komputasi performa tinggi di NVIDIA Developer Documentation.

## 4. AI Deployment & Web Frameworks
Platform yang mempermudah pengembang dalam melakukan deployment, hosting, dan skalabilitas aplikasi AI di cloud.

* Vercel AI SDK: Pustaka visualisasi antarmuka AI, streaming data real-time, integrasi UI komponen, dan framework multi-provider LLM tersedia di Vercel AI SDK Documentation.

## 5. Core Machine Learning (ML) Frameworks
Pustaka dasar dan ekosistem utama untuk membangun, melatih, serta mengevaluasi model machine learning dari awal.

* PyTorch: Dokumentasi framework deep learning berbasis tensor yang banyak digunakan oleh peneliti AI di PyTorch Documentation.
* TensorFlow: Panduan pengembangan model machine learning skala produksi dari Google di TensorFlow Documentation.
* Scikit-Learn: Dokumentasi algoritma machine learning tradisional seperti regresi, klasifikasi, clustering, dan prapemrosesan data di Scikit-Learn Documentation.
