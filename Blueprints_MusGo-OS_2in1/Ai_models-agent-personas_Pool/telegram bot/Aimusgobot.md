Saya dapat membantu Anda membuat dan mengelola bot Telegram. Jika Anda baru dengan Bot API, silakan lihat manualnya.

Anda dapat mengendalikan saya dengan mengirimkan perintah ini:

/newbot - buat bot baru  
/mybots - edit bot Anda  

Edit Bot  
/setname - ubah nama bot  
/setdescription - ubah deskripsi bot  
/setabouttext - ubah informasi tentang bot  
/setuserpic - ubah foto profil bot  
/setcommands - ubah daftar perintah  
/deletebot - hapus bot  

Pengaturan Bot  
/token - dapatkan token otorisasi  
/revoke - cabut token akses bot  
/setinline - aktifkan/ nonaktifkan mode inline  
/setinlinegeo - aktifkan/ nonaktifkan permintaan lokasi inline  
/setinlinefeedback - ubah pengaturan umpan balik inline  
/setjoingroups - dapatkah bot Anda ditambahkan ke grup?  
/setprivacy - aktifkan/ nonaktifkan mode privasi di grup  

Aplikasi Web  
/myapps - edit aplikasi web Anda  
/newapp - buat aplikasi web baru  
/listapps - dapatkan daftar aplikasi web Anda  
/editapp - edit aplikasi web  
/deleteapp - hapus aplikasi web yang ada  

Permainan  
/mygames - edit permainan Anda  
/newgame - buat permainan baru  
/listgames - dapatkan daftar permainan Anda  
/editgame - edit permainan  
/deletegame - hapus permainan yang ada
