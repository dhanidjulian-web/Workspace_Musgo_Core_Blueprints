  3. **Hardware Sovereignty:** Penggunaan *Multi-Vendor HSM* (minimal 3 vendor) dengan skema *Shamir Secret Sharing (2-of-3)* untuk proteksi kunci enkripsi.
  4. **Triple BlackBox Replication:** Replikasi log audit imutabel ke tiga lokasi (*Local, Offline, Cold*).

##### 1. Workflow Security Scanner & Code Audit (`.github/workflows/02-code-security-scanner.yml`)
```yaml
name: "MusGo-OS 2in1 - Autonomous Code Security Scanner & Audit"

on:
  push:
    branches: [ "main", "release/*" ]
  pull_request:
    branches: [ "main" ]
  schedule:
    - cron: '0 0 * * *' # Audit harian otomatis

jobs:
  zero-trust-security-audit:
    runs-on: ubuntu-22.04
    steps:
      - name: Checkout Source Code
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup Go Runtime Environment
        uses: actions/setup-go@v5
        with:
          go-version: '1.22'

      - name: Setup Python Environment
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Audit Hardcoded Secrets & Credentials
        run: |
          echo "[PHASE 1] Scanning for Hardcoded Secrets..."
          python3 -c "
          import os, sys, re
          secret_patterns = [r'sk-[a-zA-Z0-9]{32,}', r'GOMU_[A-Z0-9_]{8,}', r'PRIVATE_KEY']
          found = False
          for root, _, files in os.walk('.'):
              if '.git' in root: continue
              for f in files:
                  path = os.path.join(root, f)
                  try:
                      with open(path, 'r', errors='ignore') as fp:
                          content = fp.read()
                          for pat in secret_patterns:
                              if re.search(pat, content):
                                  print(f'[SECURITY VIOLATION] Secret found in {path}')
                                  found = True
                  except Exception: pass
          if found: sys.exit(1)
          "

      - name: Verify eBPF Kernel Budget Monitor Syntax
        run: |
          echo "[PHASE 2] Validating eBPF Kernel Code Integrity..."
          sudo apt-get update && sudo apt-get install -y clang llvm libelf-dev
          cd infra/resource_governance
          clang -O2 -target bpf -c kernel/ebpf_budget_monitor.c -o /dev/null

      - name: Validate MusGo Constitution Language (MCL) Signatures
        run: |
          echo "[PHASE 3] Validating Constitutional Signatures on Layer 00..."
          go run constitutional_domain/core/mcl_enforcer.go --validate-only
```

#### B. Optimasi Ekstrem VPS Tahap MVP (Level S1: 2 vCPU / 2GB RAM)
Untuk menjalankan Sovereign AI pada spesifikasi minim tanpa kegagalan *Kernel Panic (OOM)*, konfigurasi berikut wajib diterapkan secara permanen:

1. **PostgreSQL 15 Tuning (`/etc/postgresql/15/main/postgresql.conf`):**
   ```ini
   shared_buffers = 512MB      # Exactly 25% of 2GB RAM
   work_mem = 8MB              # Prevents OOM during concurrent queries
   max_wal_size = 2GB          # Reduces I/O spikes
   autovacuum = on             # Aggressive cleanup on audit tables
   ```
2. **Redis 7 Memory Enforcement (`/etc/redis/redis.conf`):**
   ```ini
   maxmemory 256mb
   maxmemory-policy allkeys-lru
   ```
3. **Async Worker Limit & Process Constraint:**
   * Pekerja AI (*AI Worker*) dibatasi tepat **1 proses tunggal** pada VPS 2GB.
   * Seluruh panggilan API wajib menggunakan model *asynchronous non-blocking*.
