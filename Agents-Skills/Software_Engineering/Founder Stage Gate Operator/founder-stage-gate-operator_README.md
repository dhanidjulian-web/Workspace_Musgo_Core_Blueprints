# Founder Stage-Gate Operator

A single ready-to-install `SKILL.md` for Codex-style local agent workflows.

This skill turns an AI agent into a stage-gated founder operator for solo
founders, indie hackers, and small software teams. It helps decide whether to
validate an idea, scope an MVP, prepare AI coding context, review PMF signals,
launch, audit founder bottlenecks, or think about scale and moat.

## Compatibility & Independence

This is an independent `SKILL.md` workflow for Codex-style local agent
workflows.

It is not affiliated with, endorsed by, sponsored by, certified by, or owned by
any AI platform or marketplace.

The skill can be adapted to any agent environment that supports
instruction-based workflow files.

## What You Get

- One complete `SKILL.md` file.
- A stage ladder for Idea, MVP, Launch, and Scale.
- Nine operating modes inside one skill:
  - Stage Diagnosis
  - Idea Validation
  - Customer Discovery
  - MVP Scope
  - AI Coding Context
  - PMF Feedback Loop
  - Launch Readiness
  - Founder Bottleneck Audit
  - Scale and Moat
- Output templates for each mode.
- Guardrails against premature building, launch, automation, and scale.
