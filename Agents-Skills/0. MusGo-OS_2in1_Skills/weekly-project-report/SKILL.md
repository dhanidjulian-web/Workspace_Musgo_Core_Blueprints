# Weekly Project Report Generator

## Overview

This skill provides a standardized template and workflow for generating clear, professional weekly project status reports with structured sections and actionable items. Ideal for team updates, stakeholder communications, and project management.

## Instructions

When the user requests a weekly project status report:

1. Gather necessary information:
   - Project name and period (e.g., Week of [Date])
   - Key achievements and progress against goals
   - Upcoming milestones
   - Risks, issues, or blockers
   - Action items with assignees and deadlines
   - Any metrics or KPIs

2. Use the following standard structure for the report:

### Laporan Status Proyek Mingguan

**Periode:** [Minggu ke-[X], Tanggal]

**Proyek:** [Nama Proyek]

#### 1. Ringkasan Eksekutif
- Ringkasan singkat kemajuan keseluruhan minggu ini.
- Status proyek secara keseluruhan (On Track / At Risk / Delayed).

#### 2. Kemajuan Pekerjaan
- Daftar tugas yang diselesaikan.
- Persentase penyelesaian milestone utama.
- Highlight pencapaian penting.

#### 3. Rencana Minggu Depan
- Tugas dan milestone yang akan dikerjakan.
- Target deliverables.

#### 4. Risiko dan Isu
- Daftar risiko/isue saat ini.
- Dampak dan mitigasi yang direncanakan.

#### 5. Item Tindakan (Action Items)
Gunakan format tabel:
| No | Tindakan | Penanggung Jawab | Deadline | Status |
|----|----------|------------------|----------|--------|
| 1  | ...      | ...              | ...      | ...    |

#### 6. Metrik dan KPI
- Metrik kunci (burndown, completion rate, dll).

3. Ask for missing details if information is incomplete.
4. Generate the report in professional Markdown or suggest export to DOCX/PDF.
5. Keep language formal, objective, and concise. Support both Indonesian and English as needed.
